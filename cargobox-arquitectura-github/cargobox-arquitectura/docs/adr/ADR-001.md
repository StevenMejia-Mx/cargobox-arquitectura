# ADR-001: Domain Model para comandos y consultas directas para lectura

| Campo | Contenido |
|---|---|
| Título | Domain Model para comandos y consultas directas para lectura |
| Estado | Aceptada (2026-10-12) |
| Contexto | Las historias US01, US04, US05 y US06 tienen reglas de límites, orden de estados, máximo de 2 intentos y evidencia obligatoria. El BRD reporta eventos de rastreo incompletos. US09 solo consulta. |
| Alternativas | Transaction Script (rápido, pero repite validaciones y puede olvidar el evento de rastreo); Table Module (acopla el dominio a las tablas). |
| Decisión | Usar Domain Model con el agregado Guía para todo lo que cambia el estado, y consultas directas a un modelo de lectura para US09. |
| Consecuencias | (+) Reglas en un solo lugar y probables sin base de datos. (−) Más clases y mapeo con repositorio. Trabajo posterior: agregar US02, US10–US15 sobre el mismo agregado. |
| Trazabilidad | US01, US04, US05, US06, US09; RN-01 a RN-08; TR-02, TR-04 |
